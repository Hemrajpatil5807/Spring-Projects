# Spring-MVC and Spring-Boot project of Bank Managemnt System and Construction Site Management System
The Construction Site Management System is a Spring Boot–based microservices application designed to streamline the management of construction projects, materials, expenses, and site activities.
It replaces traditional manual or spreadsheet-based management with a centralized, digital platform that enables real-time monitoring, resource tracking, and expense control across multiple construction sites.

Originally built as a Spring MVC + Hibernate monolithic application, the system has been migrated to a microservices architecture using Spring Boot and Spring Cloud, ensuring modularity, scalability, and independent service deployment.
